# VCT Web Dashboard 🌐

A lightweight web interface for managing your VCT tool configurations. 

Easily preview skins, toggle visual assets, and manage your local inventory database directly from your browser.

## ✨ Features
- **Real-time Preview:** See how assets look before applying them.
- **Config Management:** Save and load custom presets.
- **Inventory Sync:** Local database integration.

## 🚀 Quick Start

```bash
git clone https://github.com/Visual-Customization-Tools/vct-web-panel.git
cd vct-web-panel
npm install
npm run dev
